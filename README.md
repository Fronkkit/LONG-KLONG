# LONG-KLONG — Loy Krathong Online

ลอยกระทงออนไลน์กับแฟน ชวนทุกคนมาลอยในแม่น้ำเดียวกันแบบ realtime ลอยคู่ผูกด้ายแดงได้ และแท็กได้ว่าใครมาลอยบ้าง

- ไม่ต้อง build เป็นหน้าเว็บ static (HTML + CSS + JS)
- ฐานข้อมูลและ realtime ใช้ **Supabase** (ฟรี)
- โฮสต์บน **GitHub Pages** (ฟรี)

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บทั้งหมด |
| `style.css` | หน้าตา (ธีมคืนวันเพ็ญ) |
| `app.js` | ตัวแอป: ห้อง แม่น้ำ realtime ประดิษฐ์กระทง แท็ก การ์ด |
| `config.js` | **ใส่ Supabase URL + anon key ตรงนี้** |
| `supabase/schema.sql` | สร้างตารางทั้งหมดใน Supabase (รันครั้งเดียว) |

## ติดตั้ง (ประมาณ 15 นาที)

### 1. ตั้งค่า Supabase
1. supabase.com → New project → Region **Singapore**
2. เมนูซ้าย **SQL Editor** → New query → วางทั้งไฟล์ `supabase/schema.sql` → **Run**
3. **Project Settings → API** → คัดลอก *Project URL* และ *anon / publishable key* ไปใส่ใน `config.js`
   (ห้ามใช้ `service_role` / secret key)

### 2. เอาขึ้น GitHub Pages
1. สร้าง repo ชื่อ `LONG-KLONG` แบบ **Public**
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ใช้ GitHub Desktop หรือ git push ก็ได้ หรือลากไฟล์ใส่หน้าเว็บ *Add file → Upload files*)
3. repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
4. รอประมาณ 1 นาที เว็บจะอยู่ที่ `https://<github-username>.github.io/LONG-KLONG/`

### 3. ทดสอบ
- เปิดลิงก์บนมือถือ → สร้างห้อง → ปล่อยกระทง
- กด **ชวนคน** → ส่งลิงก์ให้อีกเครื่อง → อีกฝ่ายปล่อยกระทง ต้องโผล่ในจอเราทันทีโดยไม่ต้องรีเฟรช

## ฟีเจอร์ในเวอร์ชันนี้
- ห้องคู่รัก / ห้องกลุ่ม (ใช้ลิงก์หรือโค้ด) / แม่น้ำสาธารณะ
- ประดิษฐ์กระทง: ฐาน ดอกไม้ คำอธิษฐาน (เลือกให้ทุกคนเห็นได้ หรือเก็บไว้คนเดียวในเครื่อง)
- ลอยคู่ผูกด้ายแดง: กระทงสองใบลอยติดกันไป
- แท็กคนที่ลอยด้วย และ "ลอยให้" คนที่มาไม่ได้
- หน้า "ใครมาลอยบ้าง" มีตัวกรอง และปุ่มสะกิดคนที่ยังไม่ลอยผ่าน LINE
- รีแอ็กชันแสงเทียนกับหัวใจ แบบ realtime
- การ์ดความทรงจำ บันทึกเป็นรูปหรือแชร์ได้

## ข้อจำกัดที่ควรรู้ (เวอร์ชันแรก)
- ยังไม่มี login ใช้ชื่อเล่นที่เก็บในเครื่อง คนที่รู้โค้ดห้องเข้ามาได้ทุกคน
- คำอธิษฐานแบบ "ทุกคนในห้องเห็น" ใครที่มีลิงก์ห้องก็อ่านได้ ส่วนแบบ "เก็บไว้คนเดียว" ไม่ถูกส่งขึ้นเซิร์ฟเวอร์
- ยังไม่มีระบบกรองคำหยาบ
